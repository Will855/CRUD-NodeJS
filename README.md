# CRUD / REST API con Node.js

API RESTful desarrollada en Node.js para la gestión de usuarios, incluyendo login con seguridad hash (bcrypt) y manejo estructurado de errores.

## Características
- Endpoints completos para operaciones CRUD (Crear, Leer, Actualizar, Eliminar).
- Autenticación y cifrado de contraseñas mediante bcrypt.
- Control avanzado y captura de errores (Middlewares).
- Conexión a base de datos para persistencia de datos.

## Tecnologías
- Node.js
- Express.js
- Bcrypt (Seguridad Hash)
- Base de Datos (SQL / NoSQL)
